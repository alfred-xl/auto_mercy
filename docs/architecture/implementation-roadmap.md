# Implementation roadmap

Each future phase is a controlled change set with an explicit gate. A phase may refine implementation details, but changing a confirmed product contract in these documents requires a recorded architecture decision and cross-document update. Do not advance merely because code compiles.

- **Phase 4 — Filament Vehicle and Inventory Management Dashboard: Complete (2026-08-29).** The private admin now includes policy-backed vehicle, gallery, reference-data, car-stand, administrator, lifecycle, duplication, reservation-attention, and inventory-quality workflows. Detailed evidence is recorded in [`../implementation/phase-4-admin-inventory.md`](../implementation/phase-4-admin-inventory.md).

- **Phase 3 — Application Foundation and Core Vehicle Domain: Complete (2026-08-29).** The completed delivery combines the package/panel foundation, core vehicle schema and domain behavior, private administrator access, and baseline policies specified by the approved Phase 3 brief. The detailed evidence and approved variations are recorded in [`../implementation/phase-3-foundation.md`](../implementation/phase-3-foundation.md).
- Audit/status-history persistence, public inventory pages, and real inventory remain in later roadmap phases. Their exclusion from this delivery is intentional and does not mark those later roadmap deliverables complete.

## Cross-phase quality gates

Stop and resolve before advancing when any of these is true:

- Lifecycle vocabulary or visibility differs between database, admin, public UI, SEO, and analytics.
- Authorization can be bypassed by a direct route, custom Filament action, upload endpoint, preview, or internal-event endpoint.
- An upload is publicly reachable before decode/re-encode, or primary-media deletion can break a published car.
- The ₦500,000 non-refundable deposit, 14-day deadline, outstanding-payment requirement, or forfeiture reason is misstated.
- A Sold/Reserved car is represented as Available in a card, CTA, sitemap rule, metadata, cache, or `Offer`.
- Filters cannot round-trip through URL/back-forward or generate unbounded indexable combinations.
- GA4/internal data contains personal information or duplicate firing cannot be explained.
- Restore testing, queue/scheduler monitoring, or production rollback is unproven.
- A required brand, content, legal, contact, map, hosting, or privacy approval is being replaced with an invented value.

## Change control and handoff

Each phase starts by reviewing this directory and current repository state, records package/API changes since 2026-08-29, and finishes with an explicit file/change inventory, tests run, deferred items, and rollback notes. Update all affected architecture documents together when an approved decision changes; route, status, filter, content-source, and event names must never drift independently.
